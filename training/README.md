# AJPower training downloads

19 English-captioned videos, 18 minutes 41 seconds in total, with a 19-page step-by-step guide. The videos use the AJPower interface at version `3fcf2f5` with sample employees and simulated actions. There is no voice narration.

- [Download the full training pack — ZIP, 33.7 MB](https://github.com/niki08fm/ajppwerhrms/raw/refs/heads/training/2026-11-02/training/AJPower-training-pack.zip)
- [Download the step-by-step guide — PDF](https://github.com/niki08fm/ajppwerhrms/raw/refs/heads/training/2026-11-02/training/AJPower-step-by-step-guide.pdf)

If a link opens a GitHub file page, use **Download raw file**. Sign in to GitHub if the repository requires it.

## Watch or save to Google Drive

1. Download and extract the ZIP.
2. Open `AJPower-training/index.html` to search the lessons and watch them locally, or open the numbered MP4s directly from `videos/`.
3. Upload the MP4s to your Google Drive folder. Keep their numbered filenames so they stay in order.
4. Use the PDF alongside the videos. Optional English SRT captions are included; instructions are already visible on screen.
