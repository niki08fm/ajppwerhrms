# Tablet and face-flow screens

Fictional preview data; no real face images.

- [Previous site workspace](01-site-before.png): Previous main-branch overview shows counts, departments, a people list and month chart together.
- [A simpler site home](02-site-today.png): Punch first, compact live counts and department headcount. People and monthly attendance open when needed.
- [People on demand](03-site-people.png): View the current on-site list without keeping a second full list on the home screen.
- [Monthly attendance when needed](04-site-month.png): Open the monthly chart or use the separate daily and monthly registers.
- [Site home on a phone](12-site-mobile.png): The same core actions and current headcounts remain readable on smaller screens.
- [Choose the active employee](05-register-start.png): Active employees register at any site. Existing face records require a one-time HR re-registration approval.
- [Camera permission with a next step](06-camera-permission.png): A single recovery card explains how to allow camera access and preserves the registration task.
- [Face service recovery](07-face-unavailable.png): The next action is clear when face checking is unavailable; retry or return to site attendance.
- [Confirm the named employee and punch direction](08-punchout-confirm.png): Matching a face does not save the punch. The employee confirms Punch out before it is recorded.
- [A clear recorded result](09-punchout-recorded.png): The server confirmation shows the saved direction and time, with a direct return to the site.
- [An already recorded punch](10-duplicate-punch.png): A repeated punch is identified as already recorded, rather than suggesting a new attendance save.
- [Review before registration](13-registration-review.png): The employee reviews the four sample frames before upload. These preview frames contain no real biometric data.
- [Duplicate face requires HR help](11-duplicate-face-warning.png): A face belonging to another employee is shown as a warning. It is never labelled as a successful registration.
- [Location is required only for capture](14-location-required.png): Site attendance can be viewed anywhere; punching and registration check location at the moment of capture.
- [Camera permission can stay pending](15-camera-waiting.png): The employee can cancel while the browser waits for camera permission. A late camera stream is stopped.
